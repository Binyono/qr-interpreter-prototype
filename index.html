使い方（3分でテスト）

  1. 配信を開始を押すと、部屋コードとQRコードが出ます。
  2. もう1台のスマホのカメラでQRを読み取り、開いたページで言語を選ぶと字幕が届きます。
  3. この端末のマイクを押して話すと、日本語が字幕になり、相手の言語に翻訳されて表示・読み上げされます。
  4. ゲストは画面右下の🎙️ 質問を押すと、マイクのポップアップが開きます（文字入力なし）。マイクが点滅したら話すだけで、認識した質問がその言語のまま送られ、ガイドの画面に日本語訳が出ます。✕ 閉じるでまた小さなボタン戻ります。ガイドの人は📩 ゲストからの質問の「✓ 済」で消してください。受付はON/OFFできます。
  5. 参加者の画面は、上部の🔊 音声 ON/OFF と ⏩ 1.0x / 1.15x / 1.3x で、文字とスピーカーの音声を同時に楽しめます。音声ONを押した瞬間に確認音声が鳴るので、音が出るかどうかその場で分かります。
  6. 本番の精度にするには、右上の⚙️でOpenAI または Gemini のAPIキーを入れてください。

マイクは HTTPS のページでのみ使えます（Netlify Drop 等にアップしたURL）。2台を同じWi-Fiにつなぐと接続が安定します。マイクが使えない環境でも、下の入力欄から日本語を送ってテストできます。
